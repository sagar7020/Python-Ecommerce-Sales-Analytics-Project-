# Python-Ecommerce-Sales-Analytics-Project-
This project is an automated Python-based data analytics pipeline designed to process, aggregate, and visualize high-level business performance metrics from e-commerce transactional data. Using a dataset of 5,000 unique records
the script acts as an Executive Management Information System (MIS). It dynamically computes key operational metrics and exports production-grade visualization charts to evaluate category and regional performance.
Features :-
Data Cleansing: Standardizes diverse order_date raw fields into uniform Python datetime objects
ggregated Insights: Performs conditional grouping to track optimal sales variables (payment methods, product domains, and geographic dispersion).
Automated Data Visualization: Automatically processes statistical charts and saves them as publication-ready .png images using Seaborn thematic styling
  revenue_by_category.png — Distribution of gross revenue over separate product classifications.  regional_revenue_distribution.png — Statistical box plots evaluating order value distributions across regions.
